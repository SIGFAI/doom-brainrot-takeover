# Brainrot Takeover

**doom** × Brainrot · visuel · idée de team

Bring Brainrot into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Doom's imps into sneaker-wearing sharks and zombies into bat-swinging logs. Watching a shark spit laughing emojis at me was peak chaos.

## Installer

Install GZDoom with Freedoom 2, then drop mod.pk3 onto gzdoom.exe or run: gzdoom.exe -iwad freedoom2.wad -file mod.pk3. Start a new game and the imps and zombies are replaced by brainrot monsters.
